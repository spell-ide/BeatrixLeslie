# Code of Conduct

## Standard

BeatrixLeslie IDE is a technical open-source project. Contributors and maintainers keep communication direct, factual, and focused on engineering merit.

## Expected Conduct

- Critique code, architecture, and trade-offs accurately and without personal attacks.
- Provide reproducible evidence for bug reports, benchmarks, and review feedback.
- Respect maintainer scope decisions (`CONTRIBUTING.md`) and security disclosure boundaries (`SECURITY.md`).

## Unacceptable Behavior

- Harassment, personal insults, doxxing, or targeted intimidation.
- Deliberate introduction of malicious code, obfuscated payloads, credential harvesting, or telemetry.
- Disruption of issues, pull requests, or reviews through spam or bad-faith engagement.

## Enforcement

Maintainers may edit, lock, or close discussions, reject contributions, or revoke repository access from accounts that violate these standards.

Report conduct violations that cannot be addressed publicly to the maintainers via a private repository report on GitHub (`https://github.com/spell-ide/BeatrixLeslie`).
